# Amazon India-style storefront (fresh build)

A new frontend-only shopping storefront created from scratch. It does not reuse files from the uploaded ZIP.

## Run locally
1. Install Node.js 18+.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite.

## Production build
Run `npm run build`.

## Notes
- This is an independent frontend demo, not Amazon's official website.
- Product catalogue, delivery text, account and checkout are demo data.
- No real login, inventory, delivery tracking, payments or order placement are connected.
- Product and campaign imagery is loaded from Unsplash URLs and therefore requires internet access.
- The layout is designed to approximate Amazon India desktop styling; exact pixel parity cannot be guaranteed across dynamic Amazon states.
